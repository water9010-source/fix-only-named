# 退回重做只改點名的地方 Fix Only What Was Named — Claude Skill

工作被退回後，AI 常常一改就改了一大片，結果把原本對的地方改壞，又被退回一次。這個 Skill 讓 AI 只改被點名的地方，重交前逐條對照退回意見。

## 怎麼用
- 把退回意見逐條列出，每條對到要改的檔與位置。
- 只改那些地方；刪或改之前先對原本的完成標準，標準要求的字不能被刪掉。
- 重交時逐條寫「這條意見改了哪裡」，看到別的問題另外列出，不順手改。

## 限制
- 還沒有實際使用紀錄。
- Skill 內容是繁體中文。
- 不保證一定有效；AI 不一定每次都照做。
